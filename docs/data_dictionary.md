# Data Dictionary — Enterprise GTM Intelligence Platform

## Database Schema (PostgreSQL 16)

### 1. `accounts`
Stores company accounts researched or imported via CRM.

| Column | Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `account_id` | `VARCHAR(36)` | NO | Primary key (UUID v4) |
| `company_name` | `VARCHAR(255)` | NO | Company name (Indexed) |
| `industry` | `VARCHAR(100)` | YES | Industry sector |
| `website` | `VARCHAR(512)` | YES | Public website URL (Unique) |
| `employee_band` | `VARCHAR(50)` | YES | Headcount range (e.g., "50-200") |
| `company_description`| `TEXT` | YES | Narrative company description |
| `created_at` | `TIMESTAMP` | NO | Record creation timestamp |
| `updated_at` | `TIMESTAMP` | NO | Record last modified timestamp |

---

### 2. `contacts`
Stores decision-makers and stakeholders linked to an account.

| Column | Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `contact_id` | `VARCHAR(36)` | NO | Primary key (UUID v4) |
| `account_id` | `VARCHAR(36)` | NO | Foreign Key (`accounts.account_id`, CASCADE) |
| `name` | `VARCHAR(255)` | NO | Contact full name |
| `role` | `VARCHAR(100)` | YES | Job title or role |
| `email` | `VARCHAR(255)` | YES | Contact email address |
| `created_at` | `TIMESTAMP` | NO | Record creation timestamp |

---

### 3. `activities`
Tracks touchpoints and customer interactions (calls, meetings, demos, emails).

| Column | Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `activity_id` | `VARCHAR(36)` | NO | Primary key (UUID v4) |
| `account_id` | `VARCHAR(36)` | NO | Foreign Key (`accounts.account_id`, CASCADE) |
| `activity_type` | `VARCHAR(50)` | NO | call \| email \| meeting \| demo \| note |
| `activity_date` | `TIMESTAMP` | YES | Interaction occurrence date |
| `notes` | `TEXT` | YES | Meeting notes or interaction transcript |
| `created_at` | `TIMESTAMP` | NO | Record creation timestamp |

---

### 4. `opportunities`
Tracks pipeline deals and AI-identified sales opportunities.

| Column | Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `opportunity_id` | `VARCHAR(36)` | NO | Primary key (UUID v4) |
| `account_id` | `VARCHAR(36)` | NO | Foreign Key (`accounts.account_id`, CASCADE) |
| `product_id` | `VARCHAR(36)` | YES | Foreign Key (`products.product_id`, SET NULL) |
| `deal_value` | `FLOAT` | YES | Estimated deal value (USD) |
| `stage` | `VARCHAR(50)` | NO | prospecting \| qualification \| proposal \| negotiation \| closed_won \| closed_lost |
| `close_date` | `TIMESTAMP` | YES | Target or actual deal close date |
| `is_ai_generated`| `BOOLEAN` | NO | True if generated by Opportunity Agent |
| `created_at` | `TIMESTAMP` | NO | Record creation timestamp |

---

### 5. `products`
Catalogue of solutions for product-fit opportunity detection.

| Column | Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `product_id` | `VARCHAR(36)` | NO | Primary key (UUID v4) |
| `product_name` | `VARCHAR(255)` | NO | Product brand name |
| `description` | `TEXT` | YES | Capability and value proposition description |
| `target_industry`| `VARCHAR(100)` | YES | Target sectors |
| `created_at` | `TIMESTAMP` | NO | Record creation timestamp |

---

### 6. `account_reports`
Persists the full output from multi-agent research runs.

| Column | Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `report_id` | `VARCHAR(36)` | NO | Primary key (UUID v4) |
| `account_id` | `VARCHAR(36)` | NO | Foreign Key (`accounts.account_id`, CASCADE) |
| `report_json` | `JSONB` | YES | Full structured report payload |
| `account_score` | `FLOAT` | YES | Deterministic total score (0–100) |
| `score_category` | `VARCHAR(20)` | YES | High Priority \| Medium Priority \| Low Priority |
| `model_name` | `VARCHAR(100)` | YES | LLM model identifier |
| `prompt_version` | `VARCHAR(20)` | YES | Prompt version string (e.g., "1.0") |
| `generated_at` | `TIMESTAMP` | YES | Generation timestamp |
| `status` | `VARCHAR(20)` | NO | pending \| complete \| failed |

---

### 7. `research_jobs`
Tracks background job execution for multi-agent workflows.

| Column | Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `job_id` | `VARCHAR(36)` | NO | Primary key (UUID v4) |
| `account_id` | `VARCHAR(36)` | NO | Foreign Key (`accounts.account_id`, CASCADE) |
| `status` | `VARCHAR(20)` | NO | queued \| running \| complete \| failed |
| `error_message` | `TEXT` | YES | Error message if failed |
| `started_at` | `TIMESTAMP` | YES | Workflow commencement time |
| `completed_at` | `TIMESTAMP` | YES | Workflow completion time |
| `report_id` | `VARCHAR(36)` | YES | Foreign Key (`account_reports.report_id`, SET NULL) |
| `created_at` | `TIMESTAMP` | NO | Job submission timestamp |
